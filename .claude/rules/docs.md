# Docs

- **`docs/decisions.md`:** an entry per decision, `## Title (YYYY-MM-DD)`, then what was decided,
  why, and what was rejected, as bullets with a bold lead (`- **In the Commit tool window,** ...`).
  Say whose choice it was when it was Ido's ("Ido: ..."), and mark Claude's own choices as open to
  change. New entries go above the previous newest. Keep the index at the top in step: a line per
  entry. The `/decision` skill does this.
- **Measured or claimed:** a fact backed by a measurement or official documentation says so
  ("measured", or the source); anything else is labelled a claim.
- `docs/plan-v1.md` is the plan; when work departs from it, the decision says how and why.
